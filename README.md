# Shahroz – 3D Developer Portfolio (React + Vite + Three.js + Framer Motion)

## Run
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
```

## Your screenshots
Copy your images into `src/assets/projects/` (same file names as before). They are picked up automatically.

## Edit content
Everything lives in `src/data.js`: project descriptions, tech stack, demo/source links, skills, experience, contact, GitHub & LinkedIn URLs.

## Deploy
Netlify / Vercel: build command `npm run build`, publish directory `dist`.
